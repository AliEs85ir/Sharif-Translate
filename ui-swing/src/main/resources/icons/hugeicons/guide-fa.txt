راهنمای تغییر آیکون‌های برنامه
==============================

محل فایل‌ها
-----------
برنامه هنگام اولین اجرا در پوشهٔ دادهٔ خود، پوشهٔ icons را می‌سازد:
  icons/icons.json
  icons/custom/
  icons/راهنمای-آیکون‌ها.txt

در نسخهٔ قابل‌حمل، پوشهٔ داده کنار فایل برنامه است. اگر آن محل قابل‌نوشتن
نباشد، در ویندوز به %APPDATA%\Sharif Translate منتقل می‌شود. نشانی دقیق
پوشهٔ داده در گزارش شروع برنامه با عبارت «App data directory» ثبت می‌شود.

تغییر شکل یک آیکون
------------------
۱. در icons.json نام نقش موردنظر را پیدا کنید؛ مثلاً arrow-left برای
   پیکان چپ یا settings برای تنظیمات. هر نقش هرجا استفاده شود، همان شکل
   را نشان می‌دهد.
۲. برای استفاده از آیکونی که همراه برنامه است، مقدار file را به
   bundled/نام-آیکون.svg تغییر دهید. نام‌های موجود همان نام نقش‌های
   فهرست‌شده در icons.json هستند.
۳. برای آیکون تازه، در hugeicons.com فقط سبک رایگان Stroke Rounded را
   انتخاب و گزینهٔ «Download svg stroked» را بزنید. فایل را با نام ساده
   انگلیسی، مثلاً my-arrow.svg، در icons/custom/ بگذارید و مقدار file را
   به custom/my-arrow.svg تغییر دهید.
۴. فایل JSON را ذخیره کنید و برنامه را دوباره اجرا کنید. به ساخت دوبارهٔ
   برنامه یا اتصال اینترنت هنگام اجرای آن نیازی نیست.

مثال:
  "arrow-left": {
    "file": "custom/my-arrow.svg",
    "strokeWidth": 1.8
  }

تغییر رنگ و ضخامت
----------------
اگر رنگی تعیین نکنید، آیکون از رنگ متن تم فعال استفاده می‌کند.
برای رنگ تمام آیکون‌ها در یک تم، در بخش بالای فایل بنویسید:
  "themeColors": { "builtin:flat_dark": "#DDE6F2" }

برای رنگ یک آیکون در همهٔ تم‌ها، به همان نقش "color": "#2878C8"
اضافه کنید. برای رنگ همان آیکون فقط در یک تم:
  "themeColors": { "builtin:flat_dark": "#9EC8FF" }
را داخل همان نقش قرار دهید. مقدار مخصوص نقش و تم بر سایر رنگ‌ها مقدم است.
شناسهٔ تم‌ها در کد یا فایل‌های تم پروژه مشخص‌اند؛ برای تم‌های سفارشی،
شناسه از نام فایل به صورت external:نام_فایل ساخته می‌شود.

strokeWidth ضخامت خط را مشخص می‌کند؛ مقدار مجاز 0.5 تا 4 است.
اندازهٔ آیکون در هر جای رابط ثابت می‌ماند تا دکمه‌ها جابه‌جا نشوند.

اگر فایلی پیدا نشود، SVG نامعتبر باشد یا مقدار تنظیمات اشتباه باشد،
برنامه آیکون پیش‌فرض آن نقش را نمایش می‌دهد و علت را در گزارش ثبت می‌کند.
لوگوی برنامه و نشان ارائه‌دهندگان خدمات در این فایل کنترل نمی‌شوند.

آیکون‌های همراه برنامه از مجموعهٔ رایگان Hugeicons، سبک Stroke Rounded،
نسخهٔ @hugeicons/core-free-icons 4.3.5 تهیه شده‌اند. مجوز MIT و اعلان
حق‌نشر در فایل LICENSE.md همراه آن‌ها نگهداری شده است.
