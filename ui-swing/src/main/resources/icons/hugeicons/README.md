Only SVGs used by the desktop interface are included here. They were generated
from `@hugeicons/core-free-icons@4.3.5` (free Stroke Rounded icons) using
`tools/extract_hugeicons.py`. The package is MIT licensed; see `LICENSE.md`.
The package's React example is not used at runtime by this Swing application.

To update the selected set, change the role-to-export mapping in the extraction
script and run it against the matching official npm tarball. User-provided icons
belong in the app data directory's `icons/custom/` folder.
