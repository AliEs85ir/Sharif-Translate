# Contributing to Sharif Translate

The [contribution guide](../CONTRIBUTING.md) is the source of truth for development, tests, and pull requests.

The only permanent branch is `main`. Fork the [project repository](https://github.com/AliEs85ir/Sharif-Translate), make a short-lived branch from `main`, and open a pull request targeting `main`. No old upstream remote or `develop` branch is used.
